# Example duets

Both are arrangements of the built-in demo song (an original tune, not a
cover), produced with `duet-arranger demo pop|ballad -o examples`.

* `demo-pop.*` — drum-driven version: Guitar II plays bass, the piano's
  syncopated chord rhythm and kick/snare percussion.
* `demo-ballad.*` — no drums: flowing arpeggios, open-string resonance and
  harmonics, no percussion.

Open a `.atelier.json` in Atelier with **File → Import Atelier project**, or
read the `.tab.txt` in any text editor.
